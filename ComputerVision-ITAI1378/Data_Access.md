# Data and execution

Open the [course README](README.md) and individual notebooks in Colab. CNN uses Chihuahua vs Muffin image data, object detection uses Pascal VOC-style images, and VLM uses pretrained CLIP/BLIP models and example images. Inspect the exact data-loading cell, obtain data through the source/provider named there and update paths before running; do not redistribute datasets without their applicable terms. Install dependencies from requirements.txt or notebook install cells, restart runtime if prompted, and enable GPU for training/model inference where required. Large model downloads and historical library versions may affect reproducibility. A full fresh run of these three large notebooks was not completed during the portfolio review; saved artifacts are preserved, not presented as independently reproduced.
